These are variations on the Symbol Digit Modalities Test (SDMT), a neuropsychological test of processing speed, attention, and visual scanning. With a hidden key it also stresses working memory.

Match the symbols as quickly and accurately as you can.

Hard Mode
The key changes completely every batch (e.g., every 10 items).
Shuffle Key
The key's values are shuffled every batch.
Memorize Key
The key is hidden during play. You have 9 seconds to memorize it at the start of each batch.
CPM (Correct/Min)
Throughput. Higher is better.
CV (Stability)
Consistency. Lower is better (0% is perfect stability).
Switch Cost
Time lost when rule changes. Lower is better.
IES (Efficiency)
Speed adjusted for errors. Lower is better.
