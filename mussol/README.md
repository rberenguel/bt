# Mussol

> Mussol: Catalan for owl

Analogy quiz game.

The current version features "FAR analogies" generated by an LLM, designed to be creative and challenging.

Quickly hacked by Gemini (there is not much to it) and then made smoother by me. Icon by Gemini.

## Why the name

Personal pun.

### Previous versions

Earlier versions of Mussol were based on the _Analogy Question Dataset_ (CC-BY-NC-4.0). It is no longer the case, although the code still might mention some of the dataset filenames.
