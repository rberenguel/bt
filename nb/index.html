N-Back is a memory and attention training game. You must remember if the current position and color match what you saw N steps ago.

Setup

Select level: Click any square (1-9) to set N-back level

Toggle mode: Click the same square again to switch between Dual (2) and Triple (3) modes

→ Dual mode: Track 2 dimensions (position + color)
→ Triple mode: Track 3 dimensions (position + color + letter)

Start: Click the level number at top or anywhere in the bottom

Playing

Position: Press left edge if position matches N steps ago

Color: Press right edge if color matches N steps ago

Letter (Triple): Press bottom if letter matches N steps ago

Press again to toggle off. You can answer multiple dimensions per round.

Feedback

Green flash: Correct answer

Red flash: Wrong answer

Grey fill: Overall session progress (0-100 rounds)

Colorful fire fill: Perfect round streak (only increases when all dimensions correct)

Click progress icon: View training calendar (when not playing)

Daily Sessions

Achievement icons: Each completed session (100 rounds) earns a random achievement icon displayed in the play area

Daily goal: Aim for 3+ sessions per day. Icons reset daily to track today's progress

Controls

Touch/mouse: Edges

Keyboard: Z (position) / X (letter) / C (color)

Space: Start game / Pause / Resume

? key: Show this help

Escape: Close any modal

Restart: Click restart icon (↺) when paused
