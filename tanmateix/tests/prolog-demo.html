🧪 Tau Prolog for Linear Relations

This demonstrates how Prolog can handle inference and contradiction detection for linear relations.

The Prolog Program

% Facts will be added dynamically (e.g., larger(a, b, size)) % Transitive rule larger(A, C, Dim) :- larger(A, B, Dim), larger(B, C, Dim), A \= B, B \= C, A \= C. % Contradiction detection contradiction :- larger(A, B, Dim), larger(B, A, Dim). % Check if a specific relation holds holds(A, B, Dim) :- larger(A, B, Dim).
